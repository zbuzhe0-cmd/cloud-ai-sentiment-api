# Қазақша тоналдылықты талдауға арналған Cloud AI API

Қазақ тіліндегі пікірді оң, теріс немесе бейтарап санатқа бөлетін бұлттық API.

- Модель: `R3iwan/kazakh-sentiment-bert`;
- архитектура: көптілді BERT;
- санаттар: `positive`, `negative`, `neutral`;
- орындау ортасы: ONNX Runtime QUInt8;
- API: FastAPI;
- орналастыру: Docker және Render Free.

API BERT моделін қазақ тіліндегі айқын бағалау лексикасымен калибрлейді. Бұл қабат базалық модельдің шағын оқыту деректерінен туындайтын анық қателерін азайтады; жауаптағы `decision_source` өрісі шешімнің қай қабаттан алынғанын көрсетеді.

## API нүктелері

Қызмет күйін тексеру:

```http
GET /health
```

Мәтінді талдау:

```http
POST /predict
Content-Type: application/json

{"text":"Қызмет көрсету сапасы маған өте ұнады"}
```

Жауапта санат, модель сенімділігі, таза инференс уақыты, модель атауы және орындау ортасы беріледі.

## Жергілікті іске қосу

Модель файлын GitHub шығарылымынан жүктеп, `MODEL_PATH` айнымалысында оның жолын көрсету қажет. Токенизатор жолы `TOKENIZER_PATH` арқылы беріледі.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:MODEL_PATH="research\models_kz\kazakh_sentiment_uint8.onnx"
$env:TOKENIZER_PATH="R3iwan/kazakh-sentiment-bert"
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8010
```

## Render ортасында орналастыру

Репозиторийдегі `render.yaml` және `Dockerfile` орналастыруды автоматтандырады. Контейнер токенизаторды Hugging Face қорынан, ал 170,43 МБ QUInt8 моделін GitHub шығарылымынан жүктейді. Тегін дана әрекетсіздіктен кейін ұйқы режиміне өтетіндіктен, салқын іске қосу кезінде алғашқы сұрау ұзақ орындалуы мүмкін.

## Зерттеу контуры

`research/` бумасындағы сценарийлер:

- `export_kazakh_onnx.py` — қазақша BERT моделін ONNX пішіміне экспорттау және кванттау;
- `compare_kazakh_runtimes.py` — PyTorch FP32, ONNX FP32 және ONNX QUInt8 нұсқаларын қайталама өлшеу;
- `runtime_results_kz.json` — бақылау экспериментінің нәтижелері.

QUInt8 кванттауы модель көлемін 678,73 МБ-тан 170,43 МБ-қа дейін азайтады. Жылдамдық көрсеткіштері жабдыққа тәуелді, сондықтан мақсатты ортада қайталап өлшенуі тиіс.

## Шектеу

Модель шағын әрі белгілі бір тақырыптық доменге жататын деректермен үйретілген. Бейтарап және доменнен тыс мәтіндерге қатысты қателер зерттеу есебінде жеке көрсетілуі керек.
